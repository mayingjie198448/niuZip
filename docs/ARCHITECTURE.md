# niuZip 架构设计规范 (Architecture Specification)

## 1. 项目定位与设计目标

niuZip 是一款面向 **macOS (Apple Silicon M芯片 / `darwin/arm64`)** 和 **Windows x64 (`windows/amd64`)** 的现代化高性能全功能归档管理工具。

### 核心设计原则
1. **免解压极速浏览 (Zero-Extract Instant Browsing)**：仅读取中央目录或归档头部，毫秒级呈现多级虚拟文件树。
2. **零权限与高安全性 (Safe & Transactional)**：所有就地编辑、解压均受事务控制，禁止路径遍历（Zip Slip 漏洞防御），具备临时文件自动回滚与清理机制。
3. **原生性能与跨平台一致性 (Native Performance & Zero-CGO Pain)**：核心引擎首选纯 Go 高并发实现与官方原生 7-Zip CLI 嵌入，彻底规避 Windows 下 CGO 动态链接缺失和交叉编译障碍。
4. **全功能无门槛 (All-in-One Complete Edition)**：集成高级压缩、AES-256 加密、分卷压缩、包内秒搜、在线就地修改、macOS/Windows 元数据净化等完整特性。

## 3. 核心子系统设计

### 3.1 VFS (虚拟文件系统)
* **目标**：将压缩包内扁平的路径列表（如 `a/b/c.txt`）快速转换为带父子指针的树状结构 `TreeNode`。
* **数据模型**：
  ```go
  type Entry struct {
      Path         string    // 完整相对路径
      Name         string    // 文件/目录名
      IsDir        bool      // 是否目录
      Size         int64     // 未压缩大小
      PackedSize   int64     // 压缩后大小
      ModTime      time.Time // 修改时间
      IsEncrypted  bool      // 是否受密码保护
      CRC32        uint32    // 校验和
  }

  type TreeNode struct {
      Entry
      Children map[string]*TreeNode
  }
  ```
* **搜索机制**：支持扁平线性扫描（小包 < 10,000 文件）与内存索引，大小写不敏感匹配。

### 3.2 Cleaner (跨平台清洗器)
* **痛点**：macOS 产生的压缩包常包含 `__MACOSX/` 隐藏夹、`._` 前缀资源文件、`.DS_Store`，在 Windows 解压时造成困扰；反之 Windows 的文件名常含中文 GBK 乱码或特殊字符。
* **规则**：
  1. **元数据过滤**：可选跳过以 `._` 开头、名为 `.DS_Store`、以 `__MACOSX/` 开头的文件。
  2. **文件名净化**：检测并替换 Windows 非法保留字符（`\ / : * ? " < > |`）。
  3. **路径穿越防御**：严格校验 `cleanPath != ".." && !strings.HasPrefix(cleanPath, "../")`。

### 3.3 Engine Broker (引擎路由)
* **路由策略**：
  * `.zip`：优先纯 Go `PureZipEngine`（最高速度，支持多核并发，无子进程开销）。
  * `.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tbz`, `.tar.xz`, `.txz`：优先纯 Go `PureTarEngine`。
  * `.7z`, `.rar`, `.iso`, `.cab`, `.dmg` 或包含 AES 密码的归档：路由至 `SevenZipEngine`（内嵌 `7zz`）。

### 3.4 事务性就地修改 (In-Place Transactional Edit)
* **工作流**：
  1. 锁定原文件；
  2. 在同目录下创建临时工作文件 `.tmp.xxxx.zip`；
  3. 通过 `CopyRaw`（直接拷贝原始压缩流）保留未变更条目；
  4. 追加新文件，跳过删除文件；
  5. 校验新归档完整性；
  6. 原子操作重命名（`os.Rename`）覆盖原文件，并清除临时文件。

## 4. 跨平台二进制内嵌机制 (`//go:embed`)

* **macOS ARM64**：内置官方编译的 `7zz` (Apple Silicon 原生指令集)。
* **Windows AMD64**：内置官方编译的 `7zz.exe`。
* **自释放生命周期**：
  * 应用启动时计算二进制 Hash，若目标缓存路径不存在或版本不一致，则将 embed 字节流写入缓存目录并设置执行权限（macOS `0755`）。
